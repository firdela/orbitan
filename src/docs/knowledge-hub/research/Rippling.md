# Rippling — Competitor Research

## Overview

Rippling is an HR, IT, and finance automation platform for SMBs. It combines employee management, IT device management, payroll, and benefits administration in a single platform.

## Strengths

- **SMB focus** — Targets small to medium businesses (Orbitan's target segment)
- **Unified HR + IT + Finance** — Single platform for workforce, IT, and financial operations
- **Automation** — Automated onboarding, offboarding, and device management
- **Payroll** — Built-in payroll processing
- **Modern UX** — Clean, modern interface

## Weaknesses

- **No industry packs** — Generic platform, not industry-specific
- **No AI** — Limited AI capabilities
- **No wallet-native ledger** — Relies on external accounting
- **No governance framework** — No policy-as-code or shield interceptor
- **No self-improvement loop** — Static analytics, not Orbit Evolution
- **No multi-product ecosystem** — Single product

## Architecture

- Multi-tenant SaaS
- Unified data model for HR, IT, and Finance
- REST APIs for integration
- Workflow automation engine

## AI

- Limited — Basic automation, not AI-powered recommendations
- No kill switch
- No standalone AI product

## Lessons for Orbit

1. **SMB market is viable** — Rippling proves SMBs will adopt unified platforms. Orbitan targets the same segment.
2. **Unified platform** — Combining HR + IT + Finance in one platform reduces tool sprawl. Orbitan extends this to include operations, compliance, and AI.
3. **Modern UX matters** — Clean, modern interface is expected. Orbitan's Golden UI/UX Standard aligns.
4. **Payroll** — Rippling has built-in payroll; Orbitan defers to integrations (PayrollSnapshot entity exists).

## Orbit Opportunities

- **Industry packs** — Orbitan is industry-specific; Rippling is generic
- **AI intelligence** — Orbit Nexus provides AI; Rippling has limited AI
- **Governance** — Orbit Shield provides policy-as-code; Rippling has none
- **Self-improvement** — Orbit Evolution loop; Rippling has static analytics
- **Multi-product** — Orbit Core shared across products; Rippling is single product
