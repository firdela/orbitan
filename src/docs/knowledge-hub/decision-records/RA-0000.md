# RA-0000: Architecture Governance Framework

> **Status:** FROZEN — 2026-07-23
> **Version:** 1.1.0
> **Type:** Reference Architecture (Constitutional)
> **Supersedes:** None
> **Superseded by:** None
> **Related:** RA-0004, RA-0005

## Decision

RA-0000 is the "Orbitan Constitution." It establishes meta-governance for OrbitanOS:
registry schemas, capability maturity levels (L0–L5), implementation covenants, and
the Architecture Decision Lifecycle (ADL).

## Context

Before RA-0000, architectural decisions were made ad-hoc, leading to undocumented code
drift and inconsistent enforcement. A meta-governance layer was required to ensure every
future change is traceable, versioned, and resistant to silent erosion.

## Key Provisions

1. **Governance Freeze / Deliver-Only Mode:** Prevents scope creep in architectural
   planning. Milestones are hit without meta-commentary or repetitive status updates.
2. **Constitutional Integrity:** GDP-006 (Constitutional Amendment Rule) + Implementation
   Covenant (IC) keep the architecture stable, documented, and resistant to drift.
3. **Execution Strategy:** Orbitan Frozen Foundations v1.0, Orbitan MVP Charter, and
   Orbitan Build Manifest v1.0 are the final prerequisites before Build Mode.
4. **Registry Traceability:** Every RA carries `supersedes`, `superseded_by`, and
   `related_adrs` fields for full provenance.
5. **Build Readiness Checklist:** A formal gate that must pass before Discussion Mode
   turns OFF.

## Long-Term Governance Risks (Mitigated)

- **Knowledge Drift:** Mitigated by mandatory ADR linkage for RA changes.
- **AI Governance Drift:** Mitigated by Tiered Model Orchestration within Nexus.
- **Architectural Erosion:** Mitigated by automated AFR dependency validation.
